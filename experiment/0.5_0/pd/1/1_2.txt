The process begins with the customer bringing a defective computer. The CRS then checks the defect. Following this, the CRS hands out a repair cost calculation. The customer then has two options: they can either take the computer home or proceed with the repair. 

If the repair is chosen, the process splits into two parallel paths. One path involves checking the hardware and then repairing it. The other path involves checking the software and then configuring it. 

Once both paths are completed, the system functionality is tested. If the test is successful, the repair is finished. If the test is not successful, the process loops back to the point where the repair cost calculation is handed out. 

Finally, once the repair is finished, the process ends.
