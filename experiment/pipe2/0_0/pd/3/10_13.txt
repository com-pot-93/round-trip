The process begins with the "start" event. The first task is "INQ transmits the transaction data request to the IP". After this, the process moves to the next task which is "IP checks the request of the INQ". The outcome of this is determined at the "Outcome of the IP's examination". Depending on the outcome, the process moves to the next task which is "IP answers the question of the INQ". The process ends with the "end" event. All these tasks and events happen in the "INQ Lane" under the "INQ" pool.
