The process begins with "Examine claim". After examining the claim, the next step is to "Write settlement recommendation". Once the settlement recommendation is written, it needs to be checked, which is done in the "Check recommendation" step. After checking the recommendation, a decision needs to be made whether the claim is OK or not. In case the claim is not OK, the recommendation needs to be repeated, which is done in the "Repeat recommendation" step. After repeating the recommendation, it is checked again. If the claim is OK, the process proceeds with "Proceed with claim handling". Finally, the process ends.
