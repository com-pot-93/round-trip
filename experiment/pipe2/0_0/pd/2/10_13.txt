The process begins with the event "start". Following this, the INQ performs the action "INQ transmits the transaction data request". This action is then followed by the IP checking the request. After the request has been checked, the outcome of this examination is determined. Depending on the outcome, IP then proceeds to answer the question. Once the question has been answered, the process ends with the event "end". Throughout this process, there are two message flows. The first message flow is from the action "INQ transmits the transaction data request" to the action "IP checks the request". The second message flow is from the action "IP checks the request" to the action "IP answers the question".
