The process begins with the customer bringing a defective computer. The CRS then checks the defect. Following this, the CRS hands out a repair cost calculation. The customer then has the option to take the computer home or proceed with the repair. If the repair is chosen, there are two parallel paths that can be taken. One path involves checking the hardware and repairing it. The other path involves checking the software and configuring it. After both paths are completed, the system functionality is tested. If the test is successful, the repair is finished and the process ends. If the test is not successful, the process loops back to the repair stage.
