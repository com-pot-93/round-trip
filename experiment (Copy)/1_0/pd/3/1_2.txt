The process begins with the customer bringing a defective computer. The CRS then checks the defect. Following this, the CRS hands out a repair cost calculation. At this point, there are two possible paths. 

In the first path, the customer takes the computer home. In the second path, the process moves to an exclusive decision point where either the hardware is checked or the software is checked. If the hardware is checked, it is then repaired. If the software is checked, it is then configured. 

After either the hardware is repaired or the software is configured, the system functionality is tested. This leads to another exclusive decision point where either the repair is finished or the process returns to the previous exclusive decision point to check the other component (hardware or software) that was not previously checked. 

Once both the hardware and software have been checked and repaired or configured as necessary, and the system functionality has been tested, the repair is finished. The process then ends.
