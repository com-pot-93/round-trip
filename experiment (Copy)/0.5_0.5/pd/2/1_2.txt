The process begins when a customer brings a defective computer. Currently, the customer representative service (crs) checks the defect of the computer. Once the CRs has identified the issue, they provide the customer with a repair cost calculation. Based on this, the customer must decide if they will take the computer home or if they will allow repairs to take place. 

If repairs are authorized, one of two things can happen. The first possible step is a hardware check and, if necessary, a hardware repair. Alternatively, the software can be checked, and adjustments can be made if necessary. However, in order to complete either of these tasks, they must run through an exclusive decision gateway that dictates which task will happen first.

After these steps (hardware repair or software configuration) are completed, system functionality is tested. This gate is exclusive, meaning only one can allow the process to continue. If the system functionality passes as expected, the repair is signaled as finished. If not, the process goes back to the hardware check and software check stages and continues around again until the tests pass. Once the repair is finished, the process ends.
