The process begins with the start event. The first task is performed by a user, where INQ transmits the transaction data request. Once this task is completed, the process moves to the next task where IP checks the request. This task is also performed by a user. After the request has been checked, the process proceeds to the third task where IP answers the question. This task is also a user task. Once this task is completed, the process reaches the end event, marking the completion of the process. There are no gateways, pools, or message flows in this process.
